# Guess My Animal 🐾

## About the Project
Guess My Animal is a Python game where the computer thinks of a random animal, and the player tries to guess which animal it is by asking yes-or-no questions.

## How to Play
1. Run the Python program.
2. The computer selects a random animal.
3. Ask questions that can be answered with yes or no.
4. Keep asking questions until you guess the correct animal.

## Technologies Used
- Python
- AI (for answering questions)

## What I Learned
This project helped me practice Python concepts such as variables, loops, conditional statements, user input, functions, and working with AI.
